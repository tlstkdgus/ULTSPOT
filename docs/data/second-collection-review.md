`event_conditions`는 좌석 가격·예매·한도·자격을 분리한 유용한 자료다. T-011의 event_sessions/booking_windows와 구조가 달라 무조건 파일명을 바꾸거나 조건을 잘라 적재하면 안 된다. 원문 조건을 보존한 채 회차·대상별 매핑이 필요한 **개발 후속 작업**이다. 수집팀에 전체 재작성을 요구하지 않는다.

출처 566건은 모두 검수대기다. 파일상 원문 미열람은 163건이다. 아티스트 공식 URL은 12건 기재·216건 미확인으로, 첫 차수 6건 기재보다 보완됐지만 전체 검증은 아니다. 현재 운영 상태가 미확인인 장소는 7곳이며 나머지 2곳도 상설 개방 장소를 뜻하지 않는다.
