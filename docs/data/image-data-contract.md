# 행사·장소 이미지 데이터 계약

현재 수집본 assets는 0건이다. 이미지 URL이 있다는 사실만으로 화면 게시를 승인하지 않는다. 아래는 내부 수집·검수 계약이며 자동 권리 판정이나 법률 판단이 아니다.

## 수집팀 전달 내용

기존 행사/장소 ID를 유지하고 `events.image_asset_id`, `places.image_asset_id`에 assets의 ID를 연결한다. 사진이 없거나 사용 범위가 확인되지 않으면 미확인으로 남긴다. 기존 아티스트 이미지 연결도 같은 assets를 사용한다.

| assets 필드 | 기록할 내용 |
|---|---|
| asset_id | 유지할 고유 ID |
| original_url | 이미지 원본 HTTPS 주소 |
| source_page_url | 해당 이미지가 실린 원 게시물 HTTPS 주소 |
| rights_holder | 확인한 권리자, 모르면 미확인 |
| permission_status / evidence_reference | 수집된 허용 상태와 라이선스·직접 허락의 근거. 미확인을 허용으로 변경하지 않음 |
| allowed_use | 이 서비스 웹 게시·복제·크롭 등 확인된 이용 범위, 제한 포함 |
| attribution | 요구되는 저작자/출처 표시 문구 |
| expires_at | 사용 허락 만료 시각, 알면 시간대 포함 ISO 8601 |
| rights_checked_at / reviewer_alias | 권리 근거를 확인한 시각과 검수자 별칭 |
| alt_ko / alt_en | 실제 이미지 내용을 설명하는 한국어/영어 대체 텍스트 |
| modification_note | 크롭·편집 제한과 실제 변경 기록 |
| file_reference | 허용 범위를 검수한 후 보관한 파일 참조 |

원문 주소·허용 범위·만료를 확인할 수 있는 자료부터 요청한다. 무단 복사나 이미지 생성으로 실제 행사 포스터를 대체하지 않는다. 행사 날짜와 장소가 변경되면 포스터의 내용도 현재 안내와 대조한다.

## 개발 역할과 공개 경계

- Codex: 위 메타데이터 수용, ID 참조·HTTPS·시각 형식 검사. 이 검사는 허가의 진위나 이미지 내용까지 검증하지 않는다.
- Claude: 언어 선택·번역 UI, 카드와 이미지 영역, 사진 미제공/로드 실패 상태, 대체 텍스트와 출처 표시. 수집 CSV를 직접 브라우저에서 읽지 않는다.
- 공개 어댑터는 후속 구현이다. 그 전에는 원본 URL/permission_status만 보고 이미지를 자동 게시하거나 핫링크하지 않는다. 이미지를 실제로 게시하기 전 대상·권리 근거·이용 범위·만료·출처 표시를 함께 검수한다.
- 행사/장소는 기존 name_ko/name_en 또는 title_ko/title_en을 유지한다. 번역이 없는 고유명사는 원문 표시와 구분하며, 번역을 위해 시간·예약 조건을 새로 만들어 넣지 않는다.

사용자 화면은 사진 유무와 무관하게 이름 → 일정/지역 → 예약 조건 → 선택/원문 보기 순서를 유지한다. 운영시간 미확인·예약 확정 필요 여부는 사진으로 가리지 않는다.
