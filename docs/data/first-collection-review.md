## 처리한 것

한글 설명 열 이름, 현재/과거·공식 enum, 복합 ID 구분자처럼 명확한 형식만 변환했다. 비표준 열의 소속사 라벨·메모는 별도 sidecar에 보관한다. 연도만 있는 날짜를 1월 1일로 채우거나, 공연 시작 시각으로 종료 시각을 추정하지 않았다.

로컬 `.local-data/audits/first-20260919/`의 파일:

- `original.json`: CSV 내용 보존.
- `candidate.json`: 명확한 형식만 변환한 검사 후보. **직접 적재할 수 있는 완성본이 아니다.**
- `sidecar.json`: 원본 추가 열과 메모.
- `report.json`: 원본 SHA256, 행 수, 변환 내역, 행·필드별 오류.

형식 변환 후 검사 메시지는 506건이다. **506개의 거짓 사실이라는 뜻은 아니다.** 출처 필드 이름 문제 465건이 대부분이고, 나머지는 불완전 날짜 29건·예매 시각 2건·수치형 한도 1건·장소 참조 1건·종료 시각 누락 3건·운영일 미확인 5건이다. 공개 승인과 엄격한 적재 검사는 계속 보류한다.

## 원출처 표본 확인

SM 광야 개관 공지 URL은 이번 접근에서 본문을 얻지 못했다. 현재 영업 상태 확인으로 간주하지 않았다. 다른 항목은 아직 전수 사실·권리 검수하지 않았다.
