# T-016 · 방문 데이터와 유사 서비스 검토

- 근거: Claude T-015 후속 데이터 5건 요청. 해당 기록은 별도 worktree에서 확인했다.
- 구현: 기존 장소 3건 한국어 이름/지역/Do/Get, 부작용 없는 eventCopy, HiKR 교통·입장 조건 1건, JYP 원문 확인 생일 8건, 선택 이미지 ID 및 조건 타입.
- 호환: 기존 영어 필드·일정 계산·저장 버전 유지. 검수 메타데이터가 들어간 개인 저장본은 거부. UI 파일 변경 없음.
- 결과와 UI 연결 계약: [방문 데이터](../../data/visitor-data.md). [레퍼런스 검토](../../specs/reference-service-review.md)에 관찰·운영 방식·제안을 구분했다.
- 검증: 순수 데이터 단위 테스트 2건을 Playwright 3개 프로젝트에서 6회 통과. 브라우저 UI 검증을 의미하지 않음. typecheck 오류 0, lint 오류 0·스킬 경고 94.
- 하지 않은 것: UI 연결/캡처, 실제 이미지 승인·게시, 미확인 교통/현금/수량 추정, 수집본 전체 공개, 프로덕션 배포.
- 다음: T-015 UI에서 eventCopy와 선택 메타데이터를 연결하고 통합 검증. 현재 브랜치는 T-014 기반이며 T-015 UI를 합치지 않았다.
