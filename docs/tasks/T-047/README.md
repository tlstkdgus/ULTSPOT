## 결정

- **주소는 49다.** 관광공사 기사의 29는 오기로 판단했다. 기사 스스로 "안녕인사동 복합시설 안"이라
  하고, 안녕인사동은 카카오·공식 모두 49번지다. 29번지 검색 결과는 칼국수집·찻집·한복점뿐이다.
  충돌을 두 출처의 다수결이 아니라 **제3의 독립 근거(건물 자체의 주소)**로 가렸다.
- **시간은 확정.** 두 출처가 12:00–20:00으로 일치한다.
- **휴무는 미확인**으로 문구에 남겼다. `closedDays: []`는 "휴무 없음"이 아니라 "요일 휴무 정보
  없음"이고, 화면 문구가 그 차이를 말한다.
- transit 블록은 넣지 않았다(도보 분이 없다). 출구 안내는 본문에.

## 함께 고친 것 — 포스터 원본을 WebP로

`fan-cafes.spec`의 포스터 로딩 검사가 2026-09-21~23 사이 **네 번** 깨졌다. 대기를 20→45초로 늘려도
서버를 새로 띄운 직후 mobile(DPR 2)에서 또 넘겼다. 원인은 검사가 아니라 원본이다 — 카드 이미지가
1.4~2.5MB PNG라 next/image의 첫 최적화가 그만큼 걸린다. 심사자가 모바일로 처음 여는 순간에도
같은 비용이 든다.

원본 PNG는 git 이력에 남고, 사용자가 올린 원본 파일은 주 체크아웃 `public/images/`에 그대로 있다.
