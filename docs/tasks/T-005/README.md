## 결과

구현 커밋: `e89ed3c`. 코드·문서·캡처를 묶어 push했다.

실제 장소의 출처·운영시간 확인, 개인 행사 추가/삭제, 일정 계산·수정, 기기 저장/복원/삭제, TXT 다운로드를 `/plan`에 연결한다. 가상 행사·고정 결과는 런타임에 사용하지 않는다. 현재 팬 행사 카탈로그가 없는 점을 화면에 표시한다.

일정 엔진은 날짜·휴무·운영시간·최종 입장·체류·이동 여유시간을 검사한다. 예약·미확인 시간은 제외 사유 표시. Supabase 익명 사용자 저장 코드와 RLS migration은 준비했지만 키 없는 상태에서 활성화하지 않았다.

## 결정

- 1-A 방식으로 실제 제품의 핵심 기능을 비회원 공개. 회원정보 입력 단계 없음.
- 실제 운영시간과 사용자 이동 여유시간을 구분. 실시간 교통·AI·예약 기능이라고 주장하지 않음.
- 실제 장소 정보 3건은 운영기관/매장 공식 페이지에서 개별 확인. 최신 생일카페 정보 미확보.
- T-004 기반이므로 PR base는 해당 브랜치. 앞선 PR 병합 후 base/diff 재확인.

## 검증

- 실제 플래너 프로덕션 빌드 + E2E 30건 통과(3개 뷰포트). 상세·생성·수정·저장·복원·삭제·개인 행사·다운로드·엔진 경계값 포함.
- 이전 시험 구현의 테스트 3건은 Next.js route announcer와 선택자 충돌로 실패해 수정. 최종 구현에서는 모두 통과.
- ESLint가 Playwright 생성 폴더와 경합해 실패한 문제는 생성 폴더 ignore로 수정.
- ESLint 및 TypeScript 종료 코드 각각 0. `git diff --check` 오류 0건.
- 변경 전 홈 3장, 변경 후 홈·플래너·일정 결과 9장 캡처 및 직접 열람. 데스크톱 시간 필드 잘림을 발견해 열 배치 보완 후 플래너 캡처 재확인.
- 캡처의 첫 인자 전달에서 3건 skip, 중복 실행 시 산출물 경합으로 2건 실패. 단독 재실행 9건 통과. 이후 시간 입력 UI 보완 캡처 6건 통과 및 직접 확인. 최종 보관: 변경 전 3장 + 변경 후 9장.
- 운영 DB 적용·RLS 실측·AI·배포 검증 미실행. 키/계정 설정이 필요하다.
