# T-078 · 10월 행사 보강 — 공식 팝업

| | |
|---|---|
| 상태 | 완료 |
| 브랜치 | `feat/T-078-october-popup` |
| 기간 | 2026-09-28 |
| 근거 | 사용자 "추가해"(2026-09-28). 기간 한정 행사가 10/4에 모두 끝남 |

## 찾은 것과 버린 것

| 후보 | 결과 | 이유 |
|---|---|---|
| 슈퍼드라이 × 박지훈 성수 팝업 (9/30~10/12) | **추가** | 패션비즈·한국섬유신문 2026-09-23 두 기사가 기간·주소를 같게 적음 |
| 최예나 생일카페 4곳 | 버림 | "2026"이라는 검색 요약의 원본이 2022년 갤러리 글이었음 |
| 리노 생일 광고 | 버림 | 팬앤스타 모금만 진행 중이고, 광고 확정 보도가 없음 |
| 조유리·방찬 | 버림 | 옛 게시물(아이즈원 시절)·2025년 기사 |
| X의 팬 주최 생일카페 | 못 봄 | X 원출처를 열 수 없음. 애그리게이터 복제는 하지 않음(PL-RIIPKT) |

## 동작

| 입력 / 상황 | 결과 |
|---|---|
| 필터 "팝업" | 1건 (이전 0) |
| 최애 안 고름 / 박지훈 고름 | 보임 |
| 다른 아티스트만 고름 | 숨음 |
| 일정 만들기 | 운영시간 미발표라 자동 편성하지 않음. 목록에는 담을 수 있음 |
| 10/13 | 이 날짜에 운영하지 않음 |

**하지 않은 것:** 공식 채널의 운영시간은 확인하지 못했다. 열 수 없었다.
