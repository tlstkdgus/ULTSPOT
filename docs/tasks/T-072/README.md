| 입력 / 상황 | 결과 |
|---|---|
| 공유 카드를 만드는 동안 우리 서버 요청 | 0건이어야 한다. 이제 첫 빈 시간 추천이 끝난 뒤부터 세고, "다녀왔어요" 클릭도 세는 구간에 넣었다 |

**검증:** 공유 카드를 3뷰포트에서 5번씩, 15건 통과. 전체 E2E 516건 통과, flaky 0건. lint 0건.
