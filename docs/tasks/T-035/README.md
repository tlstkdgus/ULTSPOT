## 목표

`main`에 없던 Kiro의 여정 화면과 현장 기록 DB를 가져오고, 홈 안내를 실제 4단계에 맞춘다.

## 결정

- **main 쪽에서 T-029를 가져온다.** T-029 브랜치는 T-032~T-034가 없는 낡은 기준이라 거기서 작업을 이어가면 다시 벌어진다. 충돌 없이 합쳐졌다 — Kiro가 파일 소유권을 지킨 덕이다.
- **여정 검증 오류 문구를 ja/zh에 채웠다.** 한국어에만 있어서 일본어·중국어 사용자가 "Invalid journey dates." 같은 영어를 봤을 것이다. T-026의 i18n 가드가 잡았다 — 그 가드를 넣은 이유가 정확히 이것이다.
- **홈 안내는 사용자 문구 그대로.** 설명은 한 줄로 — 4개 × 3줄이면 390px에서 화면 하나를 먹는다.
- **단계 레일 라벨을 홈과 같은 어휘로.** `최애 선택 / SPOT 고르기 / 기간 정하기 / 일정 받기`, 영어 `Your ULT / Your SPOTs / Your dates / Your itinerary`. `e2e/flow.ts`가 라벨의 단일 원천이라 거기만 고치면 됐다.
- **"이렇게 만들어요"를 지도 위로.** 설명이 장식보다 먼저다. 지도는 페이지를 닫는 그림이 됐다.
- **#43은 닫았다.** #44와 같은 수정이었고 `docs/tasks/T-034/`가 충돌했다. `shrink-0` 하나만 가져왔다.

## 하지 않은 것

- **여정 화면(`journey-planner.tsx`)의 비주얼** — Kiro 담당이고 이번엔 통합만 했다.
- **번호 충돌 재발 방지 도구** — #43과 #44가 같은 T-034를 썼다. `docs/tasks/README.md` 마지막 번호 + 1로 정하면 서로의 브랜치를 못 본다. `git branch -r | grep T-0`까지 보는 습관을 문서에 적을 만하다.

## 검증

- E2E **234건 통과**, 3건 skip(클라우드 키 없음). 데이터 **58건**. typecheck 0, lint 오류 0
- 여정 화면(2박 3일)을 3개 뷰포트로 직접 찍어 Day 탭과 미배정 목록을 확인했다
- 홈 3개 뷰포트에서 4단계 설명이 한 줄씩이고 지도가 맨 아래인 것을 확인했다
- 대표 이미지 7장 재촬영
