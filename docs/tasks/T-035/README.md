# T-035 · 여러 날 일정의 이전 이동시간 조회 취소

기준: Kiro feat/T-029-full-ux의 30020cf. Claude UI 및 Kiro 현장 기록 작업과 분리한다.

조회 도중 두 방문을 다른 날짜로 나누면 조회 구간이 0개가 된다. 기존 코드는 이 경우 요청 번호와 조회 중 상태를 갱신하지 않아 오래된 응답이 적용되거나 조회 중 표시가 남았다.

빈 구간도 이전 요청을 무효화하고 조회 상태를 해제한다. effect cleanup에서 AbortController로 요청을 취소하고 취소된 응답은 상태를 변경하지 않는다.

서버 응답을 지연시킨 뒤 장소를 다른 날짜로 옮기는 UI 회귀 검사를 추가했다. 저장 형식·디자인·SQL·대표 이미지는 변경하지 않는다.

검증 결과는 PR에 기록한다. 이 PR은 main이 아니라 Kiro 기능 브랜치를 대상으로 한다.
