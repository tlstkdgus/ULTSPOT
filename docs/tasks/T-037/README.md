- 근거: 개인 주최 생일카페 연결 및 이미지 목업 요청 (2026-09-20)

## 목표와 구현

생일카페 3건을 탐색 목록에 연결하고 원본 SVG 일러스트로 빈 이미지 영역을 채웠다. 한국어 제목·지역·설명을 함께 제공한다. 수집 자료 상태를 별도 표시하며 주최자 공지로 이동할 수 있다. 아티스트 연결이 없는 생일카페는 특정 최애의 결과에 포함하지 않는다.

## 데이터 판단

.local-data의 Perplexity b2/b3 접수본을 바탕으로 날짜·주소·주최 링크를 보존했다. X 원문은 이번 실행에서 다시 열지 못했다. 보고된 정보를 독립 확인된 정보로 승격하지 않았다. 운영시간이 없으므로 자동 편성하지 않는다. 일러스트는 실제 행사 포스터나 현장 사진이 아니다.
