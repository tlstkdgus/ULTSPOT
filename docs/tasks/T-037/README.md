# T-037 생일카페 수집 자료와 목업 카드 연결

- 상태: 리뷰 준비
- 브랜치: feat/T-037-fan-cafe-catalog
- 근거: 개인 주최 생일카페 연결 및 이미지 목업 요청 (2026-09-20)

## 목표와 구현

생일카페 3건을 탐색 목록에 연결하고 원본 SVG 일러스트로 빈 이미지 영역을 채웠다. 한국어 제목·지역·설명을 함께 제공한다. 수집 자료 상태를 별도 표시하며 주최자 공지로 이동할 수 있다. 아티스트 연결이 없는 생일카페는 특정 최애의 결과에 포함하지 않는다.

## 데이터 판단

.local-data의 Perplexity b2/b3 접수본을 바탕으로 날짜·주소·주최 링크를 보존했다. X 원문은 이번 실행에서 다시 열지 못했다. 보고된 정보를 독립 확인된 정보로 승격하지 않았다. 운영시간이 없으므로 자동 편성하지 않는다. 일러스트는 실제 행사 포스터나 현장 사진이 아니다.

## 검증

- 프로덕션 빌드 통과, 타입 검사 통과.
- lint: 오류 0, 기존 경고 94.
- 생일카페 데이터 및 탐색 테스트: 3개 뷰포트 모두 통과 (6건).
- screenshots/fan-cafes-{mobile,tablet,desktop}.png 3장 직접 확인.

## 후속

- 하이커 로고: 채팅 이미지의 로컬 원본 경로를 확보한 뒤 연결.
- 운영시간·예약 조건의 원문 확인 및 좌표 연결 후 자동 편성 검토.
- DB 마이그레이션과 새 환경 변수는 필요 없다. 프로덕션 반영은 PR 머지 후 진행.

## 사용자 제공 이미지 연결
생일카페 포스터 3장과 장소 사진 2장을 public/images에 보존하고 카드에 연결했다. 포스터는 전체 표시, 사진은 4:3이며 클릭하면 원본을 연다. 뮤직코리아 사진의 도로명 번호 134는 기존 매장 주소와 일치한다. 사용자 제공 파일이며 수집 파이프라인의 이미지 권리 승인 상태를 자동 변경하지 않았다. 카카오 JS 키는 Claude 작업 폴더에 존재함을 값 노출 없이 확인했다. 실제 지도/배포 도메인 인증은 별도 검증 대상이다.

하이커 로고도 추가 접수하여 원본 비율로 연결했다. 최종 이미지 총 6개.
