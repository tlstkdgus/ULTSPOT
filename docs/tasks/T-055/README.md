## 발견과 처리

| 등급 | 문제 | 위치 | 영향 | 처리 |
|---|---|---|---|---|
| P1 | 사진 출처 표기 대비 부족 | `place-photo.tsx` figcaption `text-text-faint` | 공공누리·Google 모두 출처 표기가 이용 조건인데 읽기 어렵다. WCAG 1.4.3 | **수정** — `text-text-muted`(8:1) |
| P2 | 숨긴 영역 안에 초점 | `google-map.tsx` `aria-hidden` | Google 지도 확대 버튼이 키보드로 잡히는데 화면 낭독기에는 이름 없는 버튼. WCAG 4.1.2 | **수정** — `role="region"` + 4개 언어 이름 |
| P2 | 촬영자 링크 터치 영역 | `place-photo.tsx` Google 촬영자 링크 | 글자 높이만큼만 눌린다 | **수정** — `min-h-11` |

## 잘 된 것

- 버튼은 전부 `h-11`(44px) 이상. 링크도 `min-h-11`.
- 사진은 `loading="lazy"`, 못 불러오면 칸을 숨긴다. 3:2 칸에 자르지 않고 담아 제3유형(변경금지)을 지킨다.
- 색은 테마 토큰만. 지도 핀도 CSS 변수를 런타임에 읽는다.
- 지도가 핀 내용이 바뀔 때만 다시 그려진다(T-052에서 고침).
- 상태 변화(주변에서 찾는 중)는 `role="status"`로 알린다.

## 바뀐 검사

- `gap-fill.spec`: 출처 표기 색이 `text-muted`(rgb 185,175,160)인지 확인. Google 지도가 뜨면 이름 붙은 영역인지 확인.
