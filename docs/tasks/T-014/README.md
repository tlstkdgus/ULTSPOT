# T-014 · Claude UI 요구사항과 이미지 데이터 연결 계약

- 목표: UI 작업은 Claude에 남기고 행사·장소 이미지 수집을 연결할 수 있게 한다.
- 구현: events/places의 image_asset_id와 assets의 원 게시물·권리 검수 시각·한/영 대체 텍스트·편집 메모를 선택 필드로 수용. 기존 이미지 참조 검사를 재사용한다.
- 분담: [Claude 전달 문서](../../claude-ui-handoff.md)의 영어 유지 지침을 한국어 기본·언어 선택으로 교체했다. 첫 화면 목적, 정보 우선순위, 사진 미제공/실패, 상태 메시지 번역을 명시했다.
- 범위: UI 코드·번역 모듈·스타일·유저 플로우 문서 본문은 Claude가 소유한다. [이미지 수집 계약](../../data/image-data-contract.md)은 Codex가 담당한다.
- 하지 않은 것: 이미지 다운로드/게시/자동 권리 승인, 공개 어댑터, DB 업로드, Claude 세션 실행·직접 전송. 실제 assets는 0건이며 이미지가 준비됐다는 뜻이 아니다.
- UI 변경 0건. 화면 캡처·UI E2E 미실행.
- 검증: 데이터 테스트 13건 통과(이미지 참조·미확인 보존·안전한 URL·시각 검사 포함), typecheck 오류 0, lint 오류 0·설치 스킬 경고 94.
