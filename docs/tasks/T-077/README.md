# T-077 · 휴무일 안내 검사의 날짜 시한폭탄

| | |
|---|---|
| 상태 | 완료 |
| 브랜치 | `fix/T-077-date-timebomb` |

| 근거 | T-076 머지 후 check:prod 3건 실패(locale.spec, 3뷰포트) |

여행 날짜 입력칸은 기본값이 오늘이다. 그런데 검사가 고정 날짜 2026-09-28을 입력했다. 그날이 오늘이 되자 값이 바뀌지 않았고, 휴무 안내가 뜨지 않았다. 9/21에도 같은 이유로 깨졌는데, 그때는 날짜만 옮겼다.
이번에는 날짜를 계산한다. 서울 기준 내일부터 찾은 첫 월요일(휴무일)과 그다음 날(여는 날)을 쓴다.

**검증:** 해당 검사 3뷰포트 3건 통과. 앱 코드는 바꾸지 않았다.
