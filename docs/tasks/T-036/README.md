# T-036 · 여러 날 일정 캘린더 내보내기

Kiro 다일 일정에 없던 캘린더 다운로드를 추가했다. T-035의 조회 취소 수정 위에 쌓은 독립 작업이다.
전체 날짜의 시각이 정해지고 충돌이 없는 방문을 한 ICS 파일로 만든다. 미배치·미확정·충돌 방문은 제외하고 개수를 표시한다. 조회 중에는 다운로드를 비활성화한다.
한국 시간을 UTC로 변환하는 기존 calendar 생성기를 재사용하며 번역은 별도 4개 언어 모듈에 둔다. SQL·저장 형식·대표 이미지는 변경하지 않는다.

검증: webpack 빌드·TypeScript 및 변경 파일 lint 통과. 캘린더·기존 여정 검사 최초 27건 통과, 안내 중복으로 실패한 선택자 3건은 수정 후 재검사 통과. 총 30건 통과.
UI 테스트에서 실제 파일 다운로드·날짜 분리를 확인하고 3개 뷰포트를 캡처해 직접 열었다. 변경 전 캡처는 미실행. 외부 API는 고정 응답을 사용했다.

Claude의 최신 UI는 Kiro 브랜치 통합 시 유지해야 한다. journey-planner에는 import와 호출 한 줄만 추가했다. 키 발급·DB 작업 없이 동작한다.
