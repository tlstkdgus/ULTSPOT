## 목표

T-022로 UI 문구는 4개 언어가 됐지만 장소 데이터는 `_ko`까지다. 일본어·중국어 화면에서 카드 본문이 영어로 나간다. Codex가 바로 착수할 수 있게 계약을 확정해 넘긴다.

## 결정

- **데이터 계약을 문서로 먼저 고정한다.** `FanEvent` 타입과 `eventCopy` 시그니처가 정해지면 Codex는 데이터를, Claude는 표시를 각자 붙일 수 있다. 같은 파일을 동시에 고치지 않아도 된다.
- **폴백은 요청 언어 → 영어.** 한국어로 떨어뜨리면 일본어 화면에 한국어가 섞인다. 일본 방문자에게 한국어는 영어보다 멀다.
- **`provenance.mode === 'reviewed'` 조건을 유지하라고 명시했다.** 지금 `eventCopy`는 검수된 항목에만 번역본을 쓰고 개인 행사는 원문을 둔다. 사용자 입력을 우리가 번역해 보여주면 안 된다.
- **`storage.ts:17`의 개인 행사 판별 목록에 새 키 8개를 더하라고 적었다.** 이 목록은 "비공개 초안에서 검수 메타데이터가 올라오면 거부한다"는 불변식이다. 새 필드를 빠뜨리면 초안으로 카탈로그 필드를 주입할 수 있게 된다. 요청서에서 가장 놓치기 쉬운 항목이라 따로 떼어 적었다.
- **번역 출처를 필드로 남기라고 요청했다.** 미검수 기계 번역을 검수된 사실처럼 보여주지 않기 위해서다. 운영시간·현금 필요 여부는 오역이 곧 헛걸음이라, 검수 전에는 번역 대상에서 빼는 편이 안전하다고 적었다.

## 하지 않은 것

- **`src/lib/trip/**` 직접 수정** — Codex 담당 범위다. 요청만 남긴다.
- **`spot-card.tsx`의 `dataLocale` 선반영** — 계약이 확정되기 전에 바꾸면 타입이 어긋난다. 바꿀 두 줄의 위치만 요청서에 적어뒀다.
- **번체 중국어(zh-Hant)** — 간체만 요청했다. `zh-TW` `zh-HK` 브라우저도 간체 화면으로 보내고 있다.
- **아티스트 이름 번역** — 요청 범위에서 명시적으로 뺐다. 팬이 아는 표기가 원표기다.

## 검증

- 문서 작업이라 코드 검증 없음. 요청서에 적은 파일·줄 번호는 `000e0f3` 기준으로 실제 확인했다:
  `event-copy.ts`의 `locale: 'ko' | 'en'`과 `provenance.mode === 'reviewed'` 조건, `storage.ts:17`의 7개 키 목록, `planner.ts`의 `FanEvent` optional 필드 배치
- Codex에 넘길 검증 항목 3건을 요청서에 포함했다(개인 행사 주입 거부, `eventCopy(e, 'ja')`가 개인 행사에 원문을 돌려주는지, 번역본 없을 때 영어 폴백)

## 후속 작업

- Codex가 계약을 확정하면 `spot-card.tsx`의 `dataLocale`·`langOf` 연결
- 일본어·중국어 문구 원어민 검수(현재 UI 문구도 미검수)
