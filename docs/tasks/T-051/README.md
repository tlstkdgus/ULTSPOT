## 배경

빈 시간 추천 카드가 글자뿐이라 어떤 곳인지 감이 오지 않았다. 지도 API 셋을 비교했다.

| 출처 | 장소 사진 |
|---|---|
| 카카오 로컬 | 없음 |
| 네이버 지역 검색 | 없음 (이미지 검색은 웹 이미지라 저작권 불명) |
| Google Places | 있음, 유료, 비구글 지도와 함께 쓰기 금지 → T-052 |
| 한국관광공사 TourAPI | 있음, 무료, 공공누리 유형 표시 |

TourAPI를 명동·홍대·성수·코엑스 주변으로 조회하니 122곳 중 109곳에 대표 사진이 있었다(제1유형 17 · 제3유형 92).

## 결정

- **이용 조건을 아는 사진만 싣는다.** `cpyrhtDivCd`가 Type1·Type3이고 주소가 관광공사 이미지 서버
  (`tong.visitkorea.or.kr`)일 때만. 그 외는 사진 없음으로 둔다. 없는 사진을 다른 데서 긁어 채우지 않는다.
- **자르지 않는다.** 제3유형은 변경 금지이고 잘라내기도 변경이다. 유형마다 다르게 그리면 실수하기 쉬워 모든 사진을
  3:2 칸에 `object-contain`으로 전체를 보여준다.
- **출처를 사진 바로 아래에 둔다.** "사진: 한국관광공사 · 공공누리 제3유형(변경금지)".
- **http → https.** 원본 주소는 http로 오지만 https로 열리는 것을 확인했다. 섞인 콘텐츠를 피한다.
- **next/image를 쓰지 않는다.** 외부 사진을 우리 서버가 변환·캐시하지 않고 브라우저가 원본에서 직접 받는다. 다음
  작업의 Google 사진은 저장이 금지라 같은 방식이어야 한다. 불러오지 못하면 사진 칸을 통째로 숨긴다.
- 넓은 화면에서는 폭을 `max-w-sm`으로 묶는다. 처음엔 카드 폭을 다 써서 1440 캡처에서 사진 한 장이 화면 절반을 차지했다.
- 빈 시간 추천 카드와 "필수 방문지 주변" 목록 둘 다에 붙인다.

## 하지 않은 것

- 카카오 후보·직접 추가한 장소·생일카페 사진. 이용 조건을 아는 출처가 없다.
- TourAPI 상세 사진(`detailImage2`). 대표 사진 한 장으로 충분하고 기능별 일 1,000건을 아낀다.

## 바뀐 검사

- `tour.spec`: 사진은 관광공사 이미지 서버·알려진 유형일 때만, https로 바꾼다, 목록 행에서 사진을 읽는다.
- `gap-fill.spec`: 사진이 보이고 잘리지 않으며(object-fit: contain) 출처가 붙는다 / 못 불러오면 깨진 이미지를 남기지 않는다.
  외부 서버에 기대지 않게 앱 안 이미지로 대신한다.
- `capture.spec`: 사진을 즉시 받게 하고 디코딩까지 기다린 뒤 찍는다. 반쯤 받은 JPEG가 위쪽만, 또는 빈 칸으로 찍혔다.
