## 목표·결과

Your spots 상단에 한글/영문/별칭 검색과 최대 5개 아티스트 선택을 연결했다. 선택은 기존 version 1 snapshot에 선택 필드로 저장되며 오래된 저장본은 전체 탐색으로 읽힌다. 선택 변경은 일정 결과를 무효화하고 관련 없는 장소 선택을 정리한다. 그룹→멤버, 개인→그룹 방향을 구분하며 공통 장소를 아티스트 관련 장소로 표시하지 않는다.

공식 프로필에서 별도 확인한 Stray Kids·멤버 8명, BLACKPINK, BABYMONSTER만 초기 목록으로 사용한다. 수집된 208건 전체를 승인하지 않았다. [출처와 구현 범위](../../data/catalog-conditions.md).

관계 날짜는 연도/월 정밀도를 보존한다. 회차와 예매 구간을 선택 탭 2개로 분리하고 기존 10개 탭 입력 및 미제공 탭의 payload 해시를 유지한다. 비공개 JSON 저장이므로 새 migration은 없다.

- `pnpm test:e2e`: 39건 통과, 실제 클라우드 opt-in 3건 미실행.

- `pnpm capture T-011 plan`: 변경 전 9장, 변경 후 12장. 모바일/태블릿/PC 21장 직접 확인. 새 선택·복원 테스트에서 가로 넘침도 확인.
- 로컬 확인: `http://127.0.0.1:3109/plan`. main 미머지·프로덕션 미배포.

## 하지 않은 것·후속

현재 아티스트 전용 검수 행사/장소는 없다. 전체 아티스트·관계 DB 공개, 승인 도구, 회차별 일정 자동 편성은 후속 작업이다. 클라우드 snapshot 필드 호환성은 연결했지만 실제 원격 왕복은 이번에 재검증하지 않았다. 테스트용 가상 행사나 미검수 이미지를 공개 카탈로그에 넣지 않았다.
