# T-030 · 지원하지 않는 브라우저 언어의 영어 기본값

사용자 선택 쿠키 → 지원 브라우저 언어 → 영어 순으로 화면 언어를 결정한다.
한국어·영어·일본어·중국어 자동 감지와 사용자 선택 저장은 유지한다.
실시간 번역이나 기존 쿠키 초기화는 하지 않는다.

T-029는 Kiro 전체 UX 작업이므로 별도 T-030 브랜치를 사용한다.
검증: 언어 E2E 27건(최초 24 통과, 서버 준비 전 연결 실패 3건 재실행 통과),
Accept-Language 누락 HTTP 응답 영어 확인, lint/typecheck 성공, webpack 프로덕션 빌드 성공.
Turbopack은 공유 node_modules junction을 프로젝트 외부 경로로 거부해 webpack으로 검증했다.
영어 기본 화면을 3개 뷰포트로 캡처한다. 변경 전 캡처는 미실행.
기존 태스크 목록의 CP949/UTF-8 혼합 3개 행을 UTF-8로 복구했다.
