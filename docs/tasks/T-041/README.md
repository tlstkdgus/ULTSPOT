# T-041 검색 없이 아티스트 탐색

전체 등록 아티스트 11개를 기본 표시하고 전체/그룹/멤버/솔로/유닛 필터를 추가한다. 검색과 함께 사용하며 선택은 필터 전환 시 유지한다. 기존 전체 둘러보기는 선택 초기화로 정정한다. 장소 화면 자동 이동은 적용하지 않는다.

공개 목록은 현재 그룹 3개, 멤버 8개다. 수집본 208개와 동일하지 않으며 미연결 인물은 만들지 않았다. 4개 언어 적용. UI와 등록 데이터 확대는 별개 후속 작업이다.

검증: 프로덕션 빌드 기반 브라우저 검사 및 캡처 결과는 PR에 기록. 최초 typecheck는 아직 생성되지 않은 Next LayoutProps로 실패하여 빌드 뒤 재검증한다.

검증 결과: webpack 프로덕션 빌드(TypeScript 포함) 통과. 변경 파일 ESLint 오류 0. 전체 목록/유형 필터/선택 유지 및 기존 검색·저장·복원 9건 통과(3개 뷰포트). pnpm capture T-041 plan 실행.

## 데이터 연결 후속
최신 incoming/artists.csv 228개를 이름·ID·유형·출처 중심으로 연결했다. 기존 검수 11개는 우선 유지한다. 수집 항목에는 수집 자료 표시를 붙이고 생일 미확인 값은 가져오지 않는다. 현재 관계의 부모 ID가 유일한 경우만 연결한다. 원본 CSV와 개인정보/내부 수집 메모는 공개 번들에 포함하지 않는다.

최신 연결 검증: 수집 228개(그룹 42, 개인 167, 유닛 19), 중복 ID 0, 없는 부모 참조 0. 목록/필터 3건 및 검색·저장·복원 6건 통과. 추가 멤버 때문에 기존 테스트의 BLACKPINK 선택자가 중복되어 그룹으로 한정한 뒤 재통과. 긴 목록은 화면 높이 이내에서 스크롤한다.

## 선택 모달
아티스트 둘러보기 버튼으로 228개 목록 모달을 열 수 있다. 기존 전체 탐색도 유지한다. native dialog의 모달 포커스/배경 비활성/Esc 닫기를 사용하며 선택은 부모 상태에 보존한다. 완료 버튼에 선택 수를 표시한다.

모달 최종 검증: 3개 뷰포트에서 열기/선택/닫기/Esc/초점 복귀/선택 유지 통과. 전체 탐색 및 검색·저장·복원 포함 고유 테스트 12건 통과. 숨겨진 모달 입력과 중복되던 테스트 선택자를 보이는 textbox 역할로 좁혀 재통과. 모달 캡처 3장 직접 확인.
