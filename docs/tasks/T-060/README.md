## 결정

- 25곳을 하나씩 바꾸지 않고 **토큰 값을 올렸다.** `--color-text-faint`: `var(--color-ink-400)`(#7c7266) → `#948a7e`.
- `ink-400`은 칩·날짜 칩의 호버 테두리에도 쓰여 그대로 두고 글자 토큰만 분리했다.
- 같은 색조에서 가장 밝은 배경(surface-2)에서도 AA를 넘는 가장 어두운 값보다 조금 여유를 두었다(4.51 → 4.69).
  보조 글씨가 본문 보조(text-muted)와 구분되도록 둘 사이 대비는 1.57이다.

| bg | 4.2 | 5.68 |
| bg-soft | 3.92 | 5.45 |
| surface | 3.7 | 5.15 |
| surface-2 | 3.3 | 4.69 |

## 같이 고친 것 — 불안정한 테스트

T-054에서 쓴 "Google 사진은 Google 지도일 때만" 검사가 `networkidle`을 기다렸는데, 로컬에 Google 키가 있어 지도 타일이
계속 받아지면서 mobile에서 60초를 넘겼다. 카드가 뜬 뒤 1.5초만 기다리도록 바꿨다(3회 × 3뷰포트 통과).

## 하지 않은 것

- 로컬 전체 실행에서만 가끔 나는 생일카페 사진 대기(fan-cafes mobile). 단독 실행은 통과. 원인은 T-048 기록 그대로 미확정.

## 검증

- 신규 `e2e/contrast.spec.ts`: 글자 토큰 3 × 배경 토큰 4 = 12쌍 모두 4.5:1 이상. 옛 값으로 되돌리면 4건 실패하는 것을 확인
- E2E 전체 451 통과 · 3 skip · 2 실패 → 실패 2건은 위 테스트(고침)와 fan-cafes mobile(알려진 로컬 불안정, 단독 통과)
- 캡처 `plan-spots`·`plan-itinerary`·`design-system` 확인
