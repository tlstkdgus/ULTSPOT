## 결정

- **팬 이벤트는 X API로 수집한다** (사용자 결정 2026-09-17). 덕플레이스·팝가 크롤링·수동 복제는 하지 않는다 — 팝가 약관이 수동 추출까지 금지.
- **틀리면 안 되는 계산(날짜·충돌·거리·테마 점수)은 규칙, 동선·설명·포스터 추출은 AI.**
- **X 유래 데이터는 B2B·B2G 판매에서 제외** (X 개발자 정책) — 기획 확인 필요.
- **데모는 가입 없이 핵심 흐름 체험** — 공지 요건이 아니라 팀 판단. 확정 필요.
- **충돌 판정은 AI 호출 전에** (기획안 §4 도식과 순서가 다름) — 불가능한 Best 3에 AI 비용·대기를 쓰지 않는다. user-flow.md §0.
- **AI가 준 시각은 쓰지 않는다.** AI는 순서·날짜만, 시각은 규칙이 재계산 (functional-spec.md §4.7).
- 기획안에 없는 수치는 전부 **[제안]** 표시 — 구현 첫날 실데이터로 조정.

## 검증

- 테마 테스트: Node 스크립트로 1,024개 응답 조합 전수 계산 — 1위 테마 256건씩 균형, 동점(혼합) 256건(25%). 혼합 기준을 "1점 차 이하"에서 "동점"으로 바꾼 근거(62.5% → 25%).
- 데이터 조사: 날짜·조건은 검색 요약이 아니라 원문 페이지에서 확인. 검색 요약이 2025년 이벤트를 2026년으로 잘못 요약한 사례 2건 발견.
- 기획안 v0.5 Word HTML: marked로 변환, 표 24개 렌더링 확인, 상대 링크 0개 남음, Chromium 스크린샷으로 첫 화면 확인.
- PRD·기능명세서·유저플로우: Mermaid 11개 Chromium 렌더링 오류 0, PRD·유저플로우의 S-xx/F-xx ID 전부 기능명세서에 정의(누락 0), 다이어그램 색을 theme.css 토큰과 대조. PDF·htm 변환 결과 표 55개·다이어그램 11개·남은 상대 링크 0개, 첫 페이지와 다이어그램 2장 눈으로 확인.
- 확인 못 함: 기획 담당자 검토. PDF 페이지 자체의 이미지 확인(pdftoppm 없음) — 같은 HTML의 화면 캡처로 대신했다.
