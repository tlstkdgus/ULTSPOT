# T-031 · 반복 안내와 홍보 문구 정리

홈과 일정 화면의 가입 불필요 문구, 준비 상황 설명, 패스 홍보 문장,
아티스트 목록 범위 안내를 4개 언어에서 제거했다. 홈 소개는 한 문장으로 줄였다.
문구 키와 컴포넌트 참조를 함께 제거했다.

운영시간 미확인, 예약 조건, 저장 오류, 출처, 검색 결과가 없는 상태는 유지한다.
기능·인증·데이터·API 변경 없음. T-030 영어 기본값 브랜치를 기반으로 한다.

검증: lint 통과, Next.js webpack 프로덕션 빌드 및 TypeScript 검사 통과.
홈·일정·언어 전환 캡처 검사 30건 통과, PNG 27장 생성.
홈과 일정 화면을 mobile/tablet/desktop에서 직접 열어 확인했다.
변경 전 별도 캡처는 미실행. 실서비스 API 연결 및 프로덕션 배포는 이번 검증에 포함하지 않았다.
