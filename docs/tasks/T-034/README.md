# T-034 · 최신 UI 언어 버튼 통합

Claude PR #42의 지구본·홈 구성을 유지하고 언어 선택 화살표에 독립된 여백을 준다.
기본 select의 브라우저별 화살표 대신 장식 SVG를 사용하며 키보드·모바일 선택 동작은 유지한다.
대표 이미지는 사용자가 이미 준비했으므로 변경하지 않는다.

동시 작업 확인: Claude 시각 작업은 main에 머지됨. Kiro는 59fd19c 이후 현장 기록 SQL·명세·테스트를 작성 중이다.
Kiro의 작업 파일 및 DB는 변경하지 않았다. 이전 로컬 T-033 수정은 Claude 태스크 번호와 겹쳐 보존하고 최신 main에서 T-034로 다시 통합했다.

검증: lint 오류 0(기존 경고 94), webpack 빌드·TypeScript 통과. 언어 회귀 27건, 홈 캡처 3건 통과. 수정 전후 3개 뷰포트를 보관하고 수정 후 이미지를 직접 확인했다.
