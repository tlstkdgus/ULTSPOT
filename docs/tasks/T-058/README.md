## 결정

- `/privacy` 페이지를 만들고 **모든 화면 하단 푸터**(© 2026 ULTSPOT · 개인정보 처리방침)에서 연다.
- 내용은 코드가 실제로 하는 일에서 옮겼다: 브라우저 저장(일정·방문 체크·가계부), 선택 클라우드 저장(익명 게스트 ID·1개),
  선택 현장 현황(동의 후·최근 2일만 공개·작성자 비공개 — 마이그레이션의 집계 함수로 확인·자동 삭제 기한 없음·포인트 장부 개별 삭제 불가),
  방문 통계(Vercel Analytics 쿠키 없음, GA4 쿠키), 외부로 가는 정보(카카오·TourAPI·Google·TypeSafe에 장소 이름·좌표·고정 관심사 문구),
  쿠키(ultspot-locale, 게스트 세션, _ga).
- 4개 언어. 언어 전환이 새로고침 없이 클라이언트 상태만 바꾸므로 푸터와 본문도 클라이언트에서 화면 언어를 따른다.
- 디자인 시스템 화면의 자체 `<footer>`를 `<div>`로 바꿨다. 공통 푸터와 겹쳐 contentinfo 랜드마크가 둘이 됐다.

## 하지 않은 것

- **문의처(개인정보 보호책임자 연락처).** 공개해도 되는 연락처가 없어 비워 두었다. 사용자에게 받아야 한다.
- 쿠키 동의 배너. 사용자가 안내 페이지 방식을 골랐다.
- 익명 계정 삭제 화면. 지금은 운영자가 Supabase 관리 화면에서 지운다.
