## 목표와 결과

실제 CSV 10개·930행을 검사했다. 기존 엄격한 importer는 추가 열 때문에 파일을 거부했으므로, 원본과 추가 메모를 보존하면서 확실한 형식만 바꾸는 별도 접수 도구를 추가했다. strict validator를 완화하지 않았다.

원본 SHA256과 original/candidate/sidecar/report JSON을 `.local-data/audits/first-20260919/`에 생성했다. 원본 파일은 수정하지 않았다. 출처 465행의 필드명 불일치를 포함해 형식 오류 메시지 506건이 남았다. 종료 행사 5건·현재 운영 미확인 장소 6곳은 공개하지 않는다. 실제 행 내용은 Git에 넣지 않고 집계와 보완 요청만 문서화했다.

## 결정·하지 않은 것

기존 ID 유지, 현재/과거·공식 표기와 명확한 열 이름만 변환한다. 연도만 있는 날짜·공연 종료 시각을 추정하지 않는다. 후보 JSON의 추가 열은 sidecar에 보존하므로 후보만 독립적으로 적재하면 안 된다. 사람 검수·공개 게시·Supabase 적재 없음. SM 공지는 이번 접근 실패, YG 공식 공연 공지 표본만 확인했다. 자료 전수 원문 검증 완료로 표시하지 않는다.
