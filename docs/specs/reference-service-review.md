## 운영에서 배울 점

덕플레이스는 탐색에 대관·광고 상품을 함께 배치하고 대관 거래 책임을 판매회원과 구분한다. 공개 화면에서 관찰한 상품 구조이며 매출 비중은 알 수 없다.

[팝가 Biz](https://biz.popga.co.kr/landing/content)는 주최자 콘텐츠 등록과 지도 채널 노출을 안내한다. 이는 직접 제보/등록을 받을 운영 경로의 사례다. ULTSPOT도 수집 파일만 반복 받기보다 주최자 수정 요청 → 비공개 검수 → 게시 버전 갱신 흐름이 필요하다. 경쟁사 제휴와 같은 권한이 우리에게 있다고 가정하지 않는다.

NOL World의 사례는 여러 행사를 여행자가 읽기 쉽게 묶은 편집형 안내다. 이런 소개글의 존재만으로 실시간 운영·재고가 검증된다고 보지는 않는다.

## 개발 우선순위

1. 한국어와 참고 교통·참여 조건을 기존 UI에 연결. 장소·행사별 출처와 확인 시각 유지.
2. 검수된 실제 행사 확보, 운영일 예외·예약·마감·취소 상태 반영. 미확인은 일정 자동 편성에서 제외하되 탐색 가능 여부는 별도 판단.
3. 정보 수정 제보와 주최자 갱신 경로, 검수 기록과 재확인 기준 마련. 행사 임박/변경 제보를 재검수 우선순위로 삼음.
4. 사용 허락을 확인한 포스터 확보, 적용 대상과 만료 관리. 승인 이미지가 없으면 명확한 빈 상태.
5. 생일별 탐색·관심 행사 저장/변경 알림은 실제 데이터와 운영 체계를 갖춘 뒤 확장.

지도·이미지·코스 생성 자체보다 **주어진 방문 시간 안에 실제 가능한 행사만 고르고 예약·특전 조건을 놓치지 않게 하는 것**을 제품 목표로 제안한다. 이는 비교를 바탕으로 한 판단이며 시장 검증 완료 주장이 아니다.

'세 서비스 모두 역·출구·도보 시간을 기본 제공'하거나 '덕플레이스의 핵심 탐색 축이 생일'이라는 주장은 이번 공개 본문만으로 전부 확인하지 못했다. NOL 사례의 교통 상세와 덕플레이스의 최애 검색·생카 지도는 직접 확인했다.
