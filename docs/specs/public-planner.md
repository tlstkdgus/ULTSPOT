# T-005 실제 비회원 여행 플래너 계약

> T-006의 [여러 아티스트 지원 계획](multi-artist-data.md)과 [수집 명세](../data/collection-brief.md)는 후속 구현 요구사항이다. 현재 이 문서의 동작에 아티스트 검색·필터·검수 임포트가 추가된 것은 아니다.

2026-09-19. 사용자는 심사자가 실제로 쓸 수 있는 제품을 요청했다. 가상 행사로 제출 흐름을 대체하는 방안은 철회한다. 이 문서는 현재 구현의 기준이며 기존 PRD·기능명세·유저플로우의 샘플 제출 결정(D-06 등)을 대체한다. 전체 기획의 미구현 기능이 완료됐다는 의미는 아니다.

## 접근과 흐름

- `/` → Plan my trip → `/plan`. 로그인·결제·사용자 API 키 발급 없이 동작한다. 두 공개 경로는 인증 서비스에 의존하지 않는다.
- 요청 시점 한국 날짜가 기본값. 영어 UI, Korea time(UTC+9). 하루 날짜·시작/종료 시각·체류시간·이동 여유시간을 입력한다.
- 실제 장소 검색·선택 → 출처와 방문 조건 확인 → 일정 생성 → 제외 이유 → 시간/선택 수정·재생성 → 기기 저장/복원/삭제 또는 TXT 다운로드.
- 주최자 공지를 확인한 사용자는 해당 날짜의 행사 사실 정보를 직접 입력해 개인 일정에 추가할 수 있다. HTTPS 원문 링크 필수, 개인정보 입력 금지 안내. 개인 입력은 플랫폼 검수 데이터나 다른 사용자에게 공개되는 목록이 아니다.
- 개인 행사 최대 12개, 일정 선택 최대 6개. 이름/조건 300자, URL 1,500자 제한. 개인 행사를 삭제 후 저장하면 저장본에도 반영된다. 현재 서버 공개 행사 등록·검수 기능은 없다.

## 일정 계산

- 선택한 최대 6개 장소의 순열·부분집합을 탐색해 방문 수 최대화, 동률은 가장 이른 종료.
- 날짜, 요일 휴무, 운영시간, 최종 입장, 체류시간, 사용자 종료 시각 검사. 운영시간 미확인 및 예약 필요한 곳은 제외 이유를 표시한다.
- 이동시간은 사용자가 지정한 15~120분 여유시간이다. 실제 거리·대중교통 API 추정으로 표현하지 않는다. 첫 장소에서 시작하며 이동 구간은 외부 지도에서 사용자가 확인한다.
- 입력 변경 시 결과 무효화. 복원 시 현행 카탈로그와 입력으로 다시 계산한다. 생성 결과를 그대로 신뢰해 복원하지 않는다.
- 지도는 주소 검색 링크이며 내장 길찾기·예약 기능이 아니다. AI 생성 결과로 표시하지 않는다.

## 저장

- 기기 저장은 명시적 버튼으로 localStorage에 초안 1개를 덮어쓴다. 복원·삭제 지원, 브라우저 데이터 삭제 시 소실. 자동 업로드하지 않는다.
- Supabase 클라우드 저장 코드는 별도 기능 플래그로 비활성화되어 있다. 키 등록·migration 적용·Anonymous Sign-Ins 활성화 후 검증해야 한다.
- 활성화 시 저장 버튼에서 익명 세션을 발급한다. 이메일·비밀번호 UI 불필요. `guest_trips.owner_id = auth.uid()` RLS로 저장/조회/수정/삭제를 제한한다. 사용자당 초안 1개, JSON 64KiB 제한.
- 클라우드는 보존·삭제 안내와 함께 명시적으로 선택한다. 세션을 지우면 복원 권한을 잃는다. 운영 활성화 전 약관/개인정보 고지, 보존·파기 운영, 봇 방어 설정을 완료한다. 키 없는 현재 상태에서 DB 적용·RLS 검증·운영 준비 완료를 주장하지 않는다.

## 대회 공지

출처: 사용자가 제공한 9/18 운영팀 공지. 로그인 없는 서비스 개방(1-A) 또는 별도 체험 서비스(1-B)가 권장되고 회원 기능 자체를 없앨 의무는 없다. ULTSPOT은 **실제 제품의 핵심 기능을 공개하는 1-A 방식**으로 진행하며 로그인 없는 접근을 유지한다.

방법 2는 개인정보 없는 테스트 계정, 방법 3은 개인정보처리방침·이용약관 게재와 대회 종료 후 투표자 개인정보의 지체 없는 파기를 요구한다. 방법 3은 체험·평가에 불리할 수 있다고 공지했다.

## 남은 실제 연동

최신 팬 행사 확보와 검수/갱신 운영, AI 추출/다국어 처리 및 평가, 실제 교통 소요시간, 서버 저장 활성화·RLS 검증, 다일 일정·공유는 미완료다. 현재 구현을 전체 제품 완료 또는 제출 준비 완료로 표기하지 않는다.
