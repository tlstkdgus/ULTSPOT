## 기능 설계에 주는 제약

1. **(9/18 공식 권장, 팀 선택 1-A) 가입 없는 핵심 체험 경로를 제공한다.** `/` → `/plan` → 날짜·시간·후보 선택 → 일정 생성·제외 사유 → 수정·다운로드. 회원 기능은 별도로 추가할 수 있다.
2. **API 키는 서버 전용.** `OPENAI_API_KEY`에 `NEXT_PUBLIC_`을 붙이지 않는다. 브라우저에서 OpenAI를 직접 호출하지 않는다.
3. **AI 실패 대비.** 심사 기간에 요청이 몰리거나 사용량 한도에 걸리면 핵심 기능이 멈춘다.
   - OpenAI 계정에 월 사용 한도를 설정한다
   - 서버에 요청 빈도 제한을 둔다
   - 실패를 표시하고 같은 입력의 기본 일정 계산으로 복구한다. 실제 결과를 샘플로 조용히 교체하지 않는다. 현재 플래너는 AI 호출 없이 동작한다.
4. **실제 정보를 사용한다.** 출처 확인된 상설 장소와 사용자가 확인해 입력한 개인 행사를 구분한다. 최신 생일카페 카탈로그 미확보 사실을 숨기지 않는다. 운영시간 미확인·휴무·예약 필요 장소는 이유와 함께 일정에서 제외한다. 가상 행사를 제출용 실제 데이터로 대체하지 않는다.
