## Vercel 보호 설정 — 실측 (2026-09-16)

같은 계정(`tlstkdgus`, Hobby)의 animal-league 프로젝트로 확인했다. 보호 설정: `ssoProtection: all_except_custom_domains`.

| 주소 형태 | 예 | 결과 |
|-----------|----|------|
| 프로덕션 도메인 | `animal-league.vercel.app` | **200 — 열림** |
| 배포별 고유 주소 | `animal-league-8599pbasr-tlstkdgus.vercel.app` | 302 → `vercel.com/sso-api` (로그인) |
| 브랜치별 주소 | `animal-league-git-main-tlstkdgus.vercel.app` | 302 → `vercel.com/sso-api` (로그인) |

→ 보호 설정을 끌 필요는 없고, **제출 칸에 프로덕션 도메인을 넣는 것**이 핵심이다. ULTSPOT 프로젝트 생성 후 같은 설정인지 다시 확인한다.

## 기능 설계에 주는 제약

1. **비로그인 체험 경로 필수.** "여행 날짜 입력 → 이벤트 매칭 결과"까지는 회원가입 없이 동작해야 한다. 로그인은 저장·공유 같은 부가 기능에만 건다.
2. **API 키는 서버 전용.** `OPENAI_API_KEY`에 `NEXT_PUBLIC_`을 붙이지 않는다. 브라우저에서 OpenAI를 직접 호출하지 않는다.
3. **AI 실패 대비.** 심사 기간에 요청이 몰리거나 사용량 한도에 걸리면 핵심 기능이 멈춘다.
   - OpenAI 계정에 월 사용 한도를 설정한다
   - 서버에 요청 빈도 제한을 둔다
   - 호출 실패 시 미리 준비한 결과(대표 시나리오)로 대체해 화면이 비지 않게 한다
4. **데이터가 비어 있으면 안 된다.** 프로덕션 Supabase에 데모용 이벤트 데이터를 넣어 둔다. 날짜를 어떻게 골라도 결과가 0건인 화면이 나오지 않도록 시연 기간에 맞춘 데이터를 준비한다.
